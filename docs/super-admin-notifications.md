# Super Admin notification centre

A notification bell on all eleven authenticated owner pages replaces the reports-only header control. It lists unresolved school-reported problems, failed invitations, failed account operations and failed school provisioning. Safe titles/statuses and canonical school names/codes link to Support tickets, Accounts or School details. Related invitation/account failures are not duplicated; a later successful invitation suppresses its earlier delivery failure. Reports persist through In Progress and disappear only after resolution/closure. Operation failures disappear after recovery. Reading/opening does not mutate any record.

The owner-only platform_admin_notifications(integer) RPC uses the existing platform authorization guard, limits results to 25 per page and returns no error text, credentials, operation fields, academic records or family datasets. The bell refreshes on open, focus, support changes and the existing 30-second timer. Empty/error states, keyboard Escape, outside-click dismissal, mobile positioning and retained results on failed refresh are supported. This is in-app notification delivery only; it sends no mail, push messages or invitations and changes no SMTP settings.
